🖼️ Canvas de FamilyBot-MD para WhatsApp

Los cinco Canvas usan POST multipart/form-data y pueden devolver el PNG directamente. Esto evita que el bot tenga que convertir Base64.

Regla recomendada

POST /api/canvas/<nombre>?apiKey=TU_API_KEY&format=image
Accept: image/png

La respuesta es image/png. En Baileys se convierte directamente a Buffer.

Baileys · plantilla universal

const fs = require('node:fs');

const form = new FormData();
form.append('avatar', new Blob([fs.readFileSync('./avatar.jpg')], { type: 'image/jpeg' }), 'avatar.jpg');
form.append('username', 'Juan');

const response = await fetch(
  'https://TU_API/api/canvas/welcome?apiKey=TU_API_KEY&format=image',
  { method: 'POST', headers: { Accept: 'image/png' }, body: form }
);

if (!response.ok) throw new Error('API HTTP ' + response.status);
const buffer = Buffer.from(await response.arrayBuffer());
await sock.sendMessage(chatId, { image: buffer, caption: 'Canvas generado' });

También puedes usar JSON/Base64

Si no envías format=image, la API conserva la respuesta JSON con result.url como data:image/png;base64,.... Así se mantiene la compatibilidad con clientes existentes.
